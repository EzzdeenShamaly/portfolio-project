# Portfolio Project

A small personal portfolio website built and managed with Git and GitHub.

## Pages

- `index.html`: home page with skills and projects
- `about.html`: short introduction
- `contact.html`: contact form
- `blog.html`: blog posts

## Version

Current release: 1.0

## How to view

Open `index.html` in any web browser. No build step is needed.
